# p1syosint — Node.js

Python/Flask gerektirmez.

## Hosting

Build/Install command:
```bash
npm install
```

Start command:
```bash
npm start
```

Alternatif doğrudan:
```bash
node server.js
```

Sunucu `PORT` ortam değişkenini kullanır ve `0.0.0.0` üzerinden dinler.
`.env` dosyasını GitHub'a yükleme.
